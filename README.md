# Last Asylum — сервер 302, на русском

Памятки событий, правила NAP, распределение городов и отчёт KvK на русском.

Сайт: https://doctorpis.github.io/302/

## Читать без интернета

Скачайте `Last-Asylum-302-RU.html` и откройте в браузере. В файле уже есть изображения, русский текст и интерактивный отчёт. VPN и доступ к исходному сайту для чтения не нужны.

## Материалы

Источник: https://asylum-c62694fa-kvk11.vercel.app/

Готовые русские версии сохранены из источника. Корейские памятки UPS переведены в текст и таблицы; оригиналы доступны для сверки. Подписи всех 87 городов переведены по смыслу и могут отличаться от названий в русской локализации игры. Ники игроков и теги альянсов сохранены.

Дата снимка указана на сайте. Даты архивных событий сохранены и не являются актуальным расписанием. Это неофициальная копия для соклановцев; материалы принадлежат их авторам.
